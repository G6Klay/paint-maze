# 染色迷宫

一个在浏览器里玩的滚球染色游戏。小球放在木头迷宫里，每次朝一个方向滚出去，一直滚到撞墙才停，中途不能拐弯。滚过的通道会被染上颜色，把所有通道都染满就过关。

整个游戏只有一个 HTML 文件，用原生 JavaScript 和 Canvas 编写，不需要框架，也不需要构建。

## 开始游戏

用浏览器打开 `paint-maze.html`。也可以把这个文件直接部署到任意静态托管服务上。

字体从 Google Fonts 加载。没有网络时会改用系统字体，不影响游戏。

## 操作

| 平台 | 移动 | 其他 |
| --- | --- | --- |
| 手机 | 往哪边划，小球就往哪边滚。手指不松开、换个方向接着划，可以连续操作 | 底部按钮 |
| 电脑 | 方向键或 `W` `A` `S` `D`，也可以用鼠标拖动 | `Z` / `Ctrl+Z` 撤销，`R` 重开，`H` 提示，`L` 选关 |

小球滚动的过程中按下的方向会排队，最多记住两步，所以连续快速操作不会丢步。

- **撤销**：退回一步，不限次数。
- **提示**：从当前局面算出下一步，在小球旁边显示箭头。如果当前局面已经无解，会建议撤销或重开。
- **重开**：回到本关起点。
- **选关**：每 10 关一章，每章换一种颜色，通关后解锁下一关。

## 星级

每关有一个目标步数：

| 星级 | 条件 |
| --- | --- |
| ★★★ | 不超过目标步数 |
| ★★ | 不超过目标步数的 1.4 倍 |
| ★ | 通关 |

进度和星级保存在浏览器的 localStorage 里。

## 关卡与难度

一共 60 关，分 6 章，棋盘逐步变大（内部尺寸，裁掉空边后可能更小）：

| 关卡 | 棋盘 |
| --- | --- |
| 1–3 | 5×6 |
| 4–8 | 6×7 |
| 9–14 | 7×8 |
| 15–21 | 8×10 |
| 22–30 | 9×11 |
| 31–40 | 10×12 |
| 41–50 | 11×13 |
| 51–60 | 12×14 |

越往后，通道占棋盘的比例越高，可以绕回头的环路和宽通道也越多，所以要做的选择更多，也更容易把自己困住。

## 原理

1. **倒着挖迷宫**：一开始整块都是实心木头。小球从起点出发，反复做一次「模拟滚动」：选一个方向和停点，把路过的格子挖成通道，再把停点后面那格永久定为墙。永久墙之后不会再被挖开，所以之前每一步的停点都一直成立，整个挖掘过程本身就是一个解，每关都保证能通。挖的时候会压低形成 2×2 大空地的走法，让通道大多是单行的。
2. **目标步数**：通道不多的关卡用 BFS 搜出真正的最少步数；规模太大时改用束搜索（每一步只保留染色最多的 400 个局面），再和挖掘路线比较，取较短的一个。
3. **排序**：每章 10 关一起生成，再按目标步数从少到多排序，保证章节内难度往上走。
4. **提示**：从当前局面先做有上限的 BFS，找不到再用束搜索。

每一关的随机种子由关卡号决定，所以同一关在任何设备上都是同一张地图。生成一章大约需要半秒，过关弹窗出现时会提前生成下一关。

## 文件

- `paint-maze.html`：游戏的全部代码，包括样式、绘制、交互、关卡生成器和求解器。
